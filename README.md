# 大学野球監督物語

架空の大学の野球部監督になり、**2部の弱小〜中堅大学から、1部優勝・全国制覇・プロ野球選手の輩出**を目指す、
ブラウザで遊べる長期育成シミュレーションです。

「強奪高校野球」（`roomhair/highbaseball-game`）のゲームシステムを**大学野球向けに拡張**したもので、
試合進行・特訓・チーム作り・引退の仕組みは、強奪高校野球のコードをそのまま移して使っています。

---

## 遊び方

ビルドは要りません。ただの HTML と JavaScript です。

```bash
python3 -m http.server 8765
# → http://127.0.0.1:8765/
```

### 1年の流れ

```
（ゲーム開始時だけ）チーム作り
        ↓
新入生入部 → 特訓 → 春リーグ → 入れ替え戦 → 春の全国大会（1部優勝のみ）
        → 特訓 → 新入生スカウト → 秋リーグ → 入れ替え戦 → 秋の全国大会（1部優勝のみ）
        → 引退（4年生） → 翌年度の新入生入部 → …
```

特別な分かれ道

- **3部で最下位** → 野球部解散 → **サッカー部**として第二の物語（冬のリーグ戦・全国大会・成長・引退・新入部員）。
  サッカーで1部優勝するか、3シーズン戦い抜くと野球部を復活できます（3部から再出発）。
- **1部で6季連続優勝**（春・秋を別々に数える） → **プロ野球に参戦するか**を選べる。
  プロではシーズンごとに「続ける／大学野球へ戻る」を選べ、戻ると**参戦直前の大学野球の状態**に戻ります。
  連続優勝の数も引き継ぐので、戻った直後のシーズンで優勝すれば再び参戦を選べます。

## 強奪高校野球から再利用しているもの

| 強奪高校野球 | このゲームでの使い方 |
|---|---|
| `sim.js`（1打席ずつの試合計算・タイブレーク・コールド・継投・勝敗投手） | そのまま。**リーグ戦は12回で引き分け**にする `maxInnings` と、調子・疲労の下駄 `formBias` だけ追加 |
| `game-screen.js`（スコアボード・打球の絵・速さ切り替え・タイム・代打代走・投手交代・途中再開） | そのまま。結果画面の見出しだけ大学向けに |
| `training.js`（選択5回・見送り3回の特訓カード） | そのまま。年2回×4年間あるので、額面だけ `CONFIG.TRAINING.SCALE` 倍 |
| `growth.js`（試合後の成長・覚醒・活躍シーン） | そのまま。**成長力・潜在能力**の倍率を追加 |
| `player.js` / `team.js`（能力・守備適性・オーダー・ハンガリー法の守備割当・スタミナ持ち越し） | 3学年 → **4学年**に拡張 |
| `ui.js` / `screens.js`（選手詳細・オーダー編集・キャプテン・チーム作りの組選び・試合前・勝敗・成長） | そのまま使い、性格・素行・調子・疲労・シーズン別成績・歩みの表示を追加 |
| `style.css`（紙面風の組み方・配色・ダークモード） | そのまま。大学の部品は `css/college.css` |
| 強奪（勝てば相手の主力を引き抜く） | 大学野球の仕様に無いので使っていない |

## 主な仕様

- **リーグ**：18大学・3部制（各6校）。各部総当たり5節、**カードは2勝先取**（引き分けは数えず、どちらかが2勝するまで続く）。
  カードを取ると勝ち点1。順位は **勝ち点 → 勝率（引き分けは分母から除く）→ 直接対決 → 得失点差 → 抽選**。
- **入れ替え戦**：1部6位×2部1位、2部6位×3部1位。2勝先取。
- **延長**：10回からタイブレーク（無死一、二塁）。リーグ戦・入れ替え戦は12回で引き分け、全国大会は決着まで。
- **全国大会**：1部優勝校だけが出場。他地区の強豪が集まる16校トーナメント（リーグより明らかに強い）。
- **選手**：1〜4年生。各学年が偏らないように人数を管理（1学年の上限9人・部員の上限34人）。
  能力（打撃・長打・走力・守備・肩・捕球／球速・球威・制球・変化球・スタミナ）に加え、
  性格（表に出ない）・素行・キャプテンシー・成長力・潜在能力・調子・疲労を持つ。
- **スカウト**：能力・性格・素行・成長力・将来性は、視察するまで「？」付きの見立て。性格はエピソードから推し量る。
  プロ志望はドラフトで指名されればプロへ、社会人志望は社会人へ、他大学とも取り合いになる。大学の評価が高いほど来てくれやすい。
- **不祥事**：素行の悪い選手が固まるほど起きやすく、キャプテンの統率とチームの雰囲気で抑えられる。
  監督は「厳しく処分する／本人に反省を促す／チーム内で解決する／大学側に報告する」から選ぶ。結果は選ぶまで分からない。
- **セーブ**：データ1〜3。節目ごとの自動保存と、明示的なセーブ（別のデータへの上書き保存も可）。
- **名前の編集**：自大学・他17大学・リーグ・春秋の全国大会・プロのリーグ/球団/シリーズ名・サッカーの大会名・選手名。
  内部ではすべてIDで持っているので、名前を変えても成績や履歴は壊れない。

## テスト

```bash
node test/run.js        # 仕様47のルートをすべて自動で通す
node test/years.js 8 10 # 10年×8回の強さの推移（バランス確認）
```

自動でうまく遊んだ場合のめやす（8回×10年の平均）：1年目のチーム力は2部平均をやや下回り、
2〜4年目に1部へ。1部優勝は20シーズンで3〜4回、全国制覇は10年で0〜1回。
